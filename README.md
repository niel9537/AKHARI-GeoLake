\# AKHARI GeoLake



Cloud-Native Spatial Lakehouse and GeoAI Engineering for Regional Development Planning.



\## Overview



AKHARI GeoLake is an open-source learning project exploring modern geospatial data engineering, spatial analytics, and AI-assisted regional development planning, using public and synthetic datasets.



\## Planned Technology Stack



\- Python 3.12

\- Docker and Docker Compose

\- PostgreSQL and PostGIS

\- DuckDB Spatial and GeoParquet

\- STAC (SpatioTemporal Asset Catalog)

\- FastAPI

\- GeoAI and Agentic AI



\## Planned Capabilities



1\. Ingest and validate geospatial datasets.

2\. Store and query spatial data efficiently.

3\. Analyze regional development indicators.

4\. Expose spatial analytics through APIs.

5\. Explore AI-assisted planning insights.



\## Project Status



Day 1: Environment setup and Git/GitHub integration in progress.
